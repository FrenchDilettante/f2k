0x1000, AddressOfEntryPoint RVA 0x1000, SizeOfImage 0x2000. No CRT
(built /NODEFAULTLIB with a custom entry point).

Imports: none. The whole image is a single .text section, 15 bytes:

    55                                push ebp

    c7 05 00 00 00 00 ef be ad de     mov dword ptr [0], 0xDEADBEEF

The store through the NULL page must fault before anything else, so
the binary has no import table at all (it never reaches an import).
